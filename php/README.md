# إدارة الأمن — نسخة PHP

تحويل كامل لبرنامج Google Apps Script إلى PHP مع تخزين JSON (بدون قاعدة بيانات).

## المتطلبات

- PHP 7.4+ (يفضّل 8.x) مع امتدادات: `json` (و`mbstring` إن وُجد)
- خادم ويب (Apache / Nginx) أو خادم PHP المدمج

## التشغيل السريع

```bash
cd amn-php
php -S localhost:8080
```

ثم افتح: http://localhost:8080/index.html

## الدخول الافتراضي

| الحقل | القيمة |
|--------|--------|
| المستخدم | `admin` |
| كلمة المرور | `admin123` |

**غيّر كلمة المرور فورًا** من زر 🔑 بعد الدخول.

## الهيكل

```
amn-php/
├── index.html      الواجهة (نفس تصميم النسخة الأصلية)
├── api.php         واجهة البرمجة (كل العمليات)
├── config.php      الإعدادات
├── lib/
│   ├── db.php      تخزين JSON + دوال مساعدة
│   └── auth.php    الجلسات والصلاحيات
├── data/           ملفات JSON (تُنشأ تلقائيًا)
│   ├── users.json
│   ├── workers.json
│   ├── attendance.json
│   ├── settlements.json
│   ├── gate.json
│   ├── log.json
│   └── sessions.json
└── uploads/        صور العاملين ودفتر البوابة
```

## الوظائف المنقولة بالكامل

- تسجيل الدخول / التسجيل / تغيير كلمة المرور
- العاملين (إضافة، تعديل، حذف، صور البطاقة والصورة الشخصية)
- تسجيل الحضور اليومي والتسوية وصرف المستحق
- سجل المرتبات مع المكافآت والخصومات والضرائب
- التقارير (حسب العامل / المكان / مجمع / خطاب الاعتماد)
- دفتر دخول البوابة مع الصور والبحث والتقارير
- إدارة المستخدمين والصلاحيات والمتابعة
- تصفير البيانات

## الصلاحيات

- `workers` — العاملين
- `attendance` — الحضور والتسوية
- `reports` — التقارير
- `gate` — دفتر البوابة
- المدير (`admin`) يملك كل الصلاحيات + إدارة المستخدمين والمتابعة

## ملاحظات

- البيانات في مجلد `data/` كملفات JSON (مع قفل ملف لمنع التعارض)
- الصور في مجلد `uploads/`
- الجلسة تنتهي بعد 6 ساعات من عدم النشاط
- تصفير البرنامج يحذف العاملين والحضور والتسويات فقط (لا يحذف المستخدمين)
- للعمل على سيرفر حقيقي: ارفع المجلد كاملًا وتأكد أن `data/` و`uploads/` قابلان للكتابة
