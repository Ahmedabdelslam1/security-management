# إدارة الأمن — نظام حضور العاملين (ويب + أندرويد)

نظام كامل لإدارة حضور وتسويات العاملين ودفتر بوابة المشرفيات، يعمل من مكانين
يتصلان بنفس قاعدة البيانات:

## محتويات المستودع

| المسار | الوصف |
|---|---|
| `Code.gs` | كود السيرفر (Google Apps Script) — قاعدة البيانات Sheets + Drive للصور + بوابة JSON للأندرويد |
| `Index.html` | نسخة الويب كاملة في ملف واحد (تُلصق في Apps Script بجوار Code.gs) |
| `appsscript.json` | ملف إعدادات مشروع Apps Script |
| `flutter_app/` | تطبيق الأندرويد الكامل (Flutter) — يتصل بنفس السيرفر |
| `AGENTS.md`, `dev-server/` | أدوات مساعدة للمطورين (غير مطلوبة للتشغيل) |

## التشغيل — نسخة الويب
1. في [script.google.com](https://script.google.com) أنشئ مشروعًا جديدًا.
2. الصق `Code.gs` ثم `Index.html` (و`appsscript.json`).
3. شغّل الدالة `setup()` مرة واحدة، ثم انشر كتطبيق ويب
   (تنفيذ باسم: أنت — الوصول: أي شخص).
4. الرابط الناتج (ينتهي بـ `/exec`) هو نفسه رابط تطبيق الأندرويد.

## التشغيل — تطبيق الأندرويد
1. أضف ملف بناء الـ APK عبر GitHub:
   **Add file ← Create new file** ← اكتب المسار بالحروف:
   `.github/workflows/build-apk.yml`
   ← الصق محتوى `flutter_app/build-apk-workflow.txt` ← Commit.
2. من تبويب **Actions** انتظر آخر تشغيل ناجح، ثم حمّل
   `security-management-apk` من قسم Artifacts وفك الضغط وثبّت الـ APK.
3. في أول تشغيل الصق رابط الويب (المنتهي بـ `/exec`) وسجّل الدخول.

> سيرفر واحد مشترك: أي تسجيل حضور أو تسوية أو بوابة من الموبايل يظهر فورًا
> في نسخة الويب والعكس. الطباعة A4 (خطاب الاعتماد وكروت المرتبات) متاحة من
> نسخة الويب.

## نسخة PHP

مجلد [`php/`](php/) يحتوي على تحويل كامل للبرنامج إلى PHP مع تخزين JSON (بدون Google Apps Script).

```bash
cd php
php -S localhost:8080
```

ثم افتح http://localhost:8080/index.html — الدخول: `admin` / `admin123`
