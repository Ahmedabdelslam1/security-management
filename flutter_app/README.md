# تطبيق إدارة الأمن — نسخة أندرويد (Flutter)

نسخة أندرويد أصلية من نظام إدارة الأمن، تتصل بنفس السيرفر (Google Apps Script)
ونفس قاعدة البيانات المستخدمة في نسخة الويب. لا حاجة لأي سيرفر جديد.

## الشاشات الجاهزة (النسخة الكاملة)
- تسجيل الدخول + مستخدم جديد + رابط السيرفر
- الحضور: تسجيل حضور يوم كامل بالعمال (الموقف، مكان الحضور، ساعات إضافية، ملاحظات)
- العاملين: عرض / إضافة / تعديل / حذف
- التسوية: صرف مستحقات العاملين مع معاينة المستحق قبل التأكيد + سجل المرتبات
- التقارير: تقرير أي عامل عن أي فترة + مشاركة كنص
- دفتر البوابة: سجلات السيارات + تصوير المستندات من الكاميرا مباشرة
- المستخدمين (للمدير): موافقة/إيقاف + صلاحيات + كلمة مرور + حذف + إضافة
- المتابعة (للمدير): المتصلون الآن + سجل النشاط بالبحث
- الإعدادات: رابط السيرفر + تغيير كلمة المرور

## كيف تحصل على ملف الـ APK بدون تثبيت أي برامج؟
1. ارفع أي تعديل على مجلد flutter_app (أو انتظر أول رفعة) — سيعمل GitHub Actions تلقائيًا.
2. افتح المستودع على GitHub ← تبويب **Actions** ← آخر تشغيل ناجح باسم
   "بناء تطبيق أندرويد (APK)".
3. تحت ملخص التشغيل ستجد قسم **Artifacts** فيه ملف `security-management-apk`.
4. حمّله وفك الضغط — داخله `app-debug.apk`.
5. انقله للموبايل وثبّته (اسمح بـ "تثبيت من مصادر غير معروفة" عند الطلب).

## أول تشغيل على الموبايل
1. في حقل "رابط التطبيق" الصق رابط نسخة الويب نفسه الذي ينتهي بـ `/exec`.
2. سجّل الدخول بنفس اسم المستخدم وكلمة المرور.

> **مهم:** بعد إضافة بوابة الـ JSON (دالة `doPost`) في Code.gs لا بد من نشر
> نسخة جديدة من تطبيق الويب (نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد)
> حتى يقبل السيرفر طلبات تطبيق الأندرويد.

## للتشغيل من الكمبيوتر (اختياري للمطورين)
```
cd flutter_app
flutter create --platforms android --org eg.security --project-name security_management .
flutter pub get
flutter run
```

## تحديث 1.11.0 — السرعة والاتصال بالويب
- **أسرع**: الساعة صارت ودجت مستقلة (كانت تعيد رسم الشاشة كلها كل ثانية)، الشاشات لا تُعاد رسمها بلا داعٍ، وفك الردود الكبيرة يتم في خيط منفصل.
- **تشغيل فوري**: آخر بيانات تُحفظ على الجهاز ويُفتح التطبيق بها مباشرة ثم تتحدث من الويب في الخلفية.
- **مزامنة ذكية**: تسأل السيرفر كل 15 ثانية عن رقم التعديل فقط (طلب خفيف)، وتتوقف في الخلفية، ولا تسحب البيانات مرتين (`rev` أصبح يأتي مع `bootstrap` — يلزم نشر نسخة جديدة من Code.gs).
- **اتصال بالويب**: شاشة «الإعدادات» أصبحت ظاهرة (القائمة + الرئيسية) وفيها تغيير رابط السيرفر واختباره، ونفس الخيار في شاشة الدخول. شريط يظهر عند انقطاع الاتصال.
- **إصلاحات**: انتهاء الجلسة يعيد المستخدم لشاشة الدخول من أي شاشة (كان يعلق على «إعادة المحاولة»)، إعادة محاولة تلقائية لطلبات القراءة، فحص حالة تحميل التحديث، فحص التحديث كل 6 ساعات بدل 20 دقيقة.
- **البناء**: الـ workflow يبني نسخة Release مباشرة (بدل بناء Debug ثم بناء Release ثانٍ داخل Gradle) فأسرع وأبسط، مع `flutter analyze` في السجل.
